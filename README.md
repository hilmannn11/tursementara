# Lithera

Situs Lithera berbasis HTML, CSS, dan JavaScript statis.

## Jalankan lokal

Di direktori ini, jalankan `python -m http.server 8000`, lalu buka `http://localhost:8000`.

## Deploy

Repository ini dapat diimpor ke Vercel sebagai proyek **Other**. Konfigurasi `vercel.json` memakai direktori ini sebagai keluaran situs tanpa proses build.
